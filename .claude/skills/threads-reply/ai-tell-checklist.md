# AI 티 자가검증 체크리스트 — 한글 답글용

답글 초안마다 이걸 돌려 **다시 쓴다.** 목표: "AI가 쓴 것 같지 않으면서, 공감으로 프로필 방문을 유도하는" 댓글.
사람의 진짜 댓글은 **짧고, 툭툭 끊기고, 완벽하지 않다.** AI 댓글은 **매끈하고, 균형 잡히고, 대구가 예쁘고, 감탄이 정형화**돼 있다.

## A. 즉시 걸러낼 AI 티 (있으면 고쳐 쓴다)

1. **기계적 대구/삼단 나열** — "A하고, B하고, C하죠" 식으로 리듬이 너무 반듯. → 하나로 줄이거나 비대칭으로.
2. **정형 감탄** — "정말 대단하세요", "확 와닿네요", "너무 인상적이에요", "깊이 공감합니다". → 더 구체적이거나 구어체로("와… 이거 진짜", "아 이거 뭔지 알아요").
3. **번역투** — "~에 대해", "~로 인해", "~라는 점에서", "~인 것 같습니다". → 우리말 구어("~때문에", "~한 것 같아요/같아요").
4. **과한 완결성** — 군더더기 없이 딱 떨어지는 문장. → 말줄임(…), 미완결, 구어 축약("~더라구요", "~거든요", "~잖아요").
5. **정중 과잉/거리감** — "귀하", "님의 게시물", 지나친 격식. → 친근한 반존대·존댓말 구어.
6. **이모지 남발·기계적 배치** — 문장마다 이모지. → 0~1개, 감정이 실릴 때만(ㅠㅠ, ㅎㅎ, ㅋㅋ가 이모지보다 자연스러울 때 많음).
7. **인터뷰어 같은 질문** — 너무 정돈된 열린 질문. → 진짜 궁금한 사람처럼 툭("그거 오래 걸려요?", "어디서 제일 막혀요?").
8. **모든 문장이 '저도~'로 시작** — 시작을 다양화(감탄·상대 인용·상황 묘사로 열기).
9. **드문/현학적 단어** — 일상 대화에 안 쓰는 어휘. → 쉬운 말로.
10. **요약형 마무리 훈수** — "결국 ~가 중요한 것 같습니다" 식 정리. → 필요 없으면 빼고, 질문이나 공감으로 끝.

## B. 자연스러운 한글 답글의 특징 (이렇게 만든다)

- **한 호흡이 짧다.** 두세 문장.
- **구어 종결**: ~더라구요 / ~거든요 / ~잖아요 / ~던가요? / ~네요.
- **감정 소리**: ㅋㅋ, ㅎㅎ, ㅠㅠ, 와, 아… (과하지 않게 1개 정도)
- **미완결·말줄임**으로 여운.
- **구체 한 조각**: 내 경험을 뭉뚱그리지 말고 사실 하나(숫자·상황·직전 경험)를 박는다.
- **진짜 질문 하나**로 끝 — 상대가 답하고 싶게.

## C. 최종 게이트 (하나라도 NO면 다시)

- [ ] 소리 내 읽었을 때 **입에 붙나?**(안 붙으면 번역투/대구 의심)
- [ ] 시작이 앞 카드들과 **겹치지 않나?**(‘저도’ 연발 금지)
- [ ] **구체적 경험 한 조각**이 들어갔나?
- [ ] **되묻는 질문**이 있나?(단, 애도·상실 글은 예외 — 질문 없이 위로만)
- [ ] 앱 언급이 있다면 **‘내가 만들었다’고 밝혔나?**(숨기면 폐기)
- [ ] 링크 없나? / 이모지 0~1개인가?
- [ ] 이 니치가 발달장애 육아면 **순수 공감인가?**(앱·홍보·훈수 0)

## D. 예시 (전/후)

- ❌ "정말 대단하세요! 매물 관리와 마케팅을 모두 혼자 하시다니 깊이 공감합니다. 어떤 매물이 가장 반응이 좋으신가요?"
- ✅ "매물에 릴스에 인스타까지 혼자 다 하시는 거예요? 와… 하루가 몸이 몇 개라도 모자라겠어요. 릴스는 보통 어떤 매물이 반응 제일 좋던가요?"

- ❌ "AI 시대에 프롬프트 역량이 핵심이라는 점에 깊이 동감합니다. 저 또한 그렇게 생각합니다."
- ✅ "이거 진짜 핵심 짚으셨네요. 결국 'AI한테 뭘 시킬지 아는 것'이 실력이더라구요. 저는 IT회사만 22년 다녔는데도 개념 몰라서 맨날 검색부터 했어요ㅋㅋ"
