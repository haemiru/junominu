# 대댓글 모드 — 붙여넣은 대화에 답글 쓰기 (모드 B)

배치 스캔(모드 A)과 반대다. **타깃을 찾지 않는다.** 사용자가 이미 가지고 있는 대화 한 덩어리를 주면, 거기에 달 답글 **추천안 3개**를 채팅으로 낸다.

> 원본 아이디어: 짱샘의 책방 레포 `/threads-reply` 커맨드의 캡처·텍스트 입력 방식.
> 이 사이트 계정(@solopreneur.jm)에 맞게 정체성·톤·출력 방식을 바꿔 옮긴 것.

---

## 1. 트리거

- "이 댓글에 대댓글 써줘" + 텍스트 붙여넣기
- 스크린샷 첨부 + "여기 답글 달아줘"
- "@아무개가 이렇게 답했는데 뭐라고 하지?"

**입력 형태 3가지**
1. **텍스트 붙여넣기** — 그대로 쓴다.
2. **스크린샷 첨부**(권장) — `Read`로 이미지를 읽어 본문·작성자·말투·댓글 순서를 뽑는다. 캡처에 글이 여러 개면, 사용자가 대상을 안 밝힌 경우 **가장 위/가운데 메인 글**을 대상으로 본다.
3. **둘 다** — 텍스트로 준 지시(대상 지정·강조할 것·톤)가 우선한다.

---

## 2. 대화 층위부터 확정한다 (틀리면 엉뚱한 답이 나간다)

답글을 쓰기 전에 **"내가 지금 누구에게 답하는가"** 를 한 줄로 적는다.

| 케이스 | 상황 | 답글이 향하는 사람 |
|---|---|---|
| A | 남의 원글에 새 댓글 | 원글 작성자 |
| B | 내 원글에 달린 댓글에 답 | 그 댓글 작성자 |
| C | 내 댓글에 달린 대댓글에 답 | 그 대댓글 작성자 |

**바로 위 글만 본다.** 더 위로 거슬러 올라간 글의 톤·주제는 참고만 하고 따라가지 않는다.

## 3. 톤

- **기본은 계정 정체성인 따뜻한 존댓말 구어체**(`voice-profile.md`). 처음 보는 사람에겐 무조건 존댓말.
- **예외**: 이미 서로 반말을 쓰고 있는 스친이면 반말로 맞춘다. 상대가 반말이어도 **초면이면 존댓말**을 유지한다.
- `voice-profile.md` §규칙을 그대로 적용한다 — 줄바꿈 문단 분리, 감정엔 ㅠㅠ/ㅋㅋ/.., 공감글엔 질문 대신 여운, 메이커글엔 진짜 구현 질문.

## 4. 추천안 3개 — 서로 달라야 한다

3개를 **다 쓰지 않는다.** 사용자가 하나를 고르거나 둘을 섞는다. 그러니 **내용이 겹치면 안 된다.**

각 안은 아래에서 **서로 다른 조합**을 쓴다:
- **핵심 자산**: ① 내 경험 한 조각 / ② 관점 재구성(프레임 바꾸기) / ③ 구체적 방법 1개 / ④ 되묻는 질문 하나로 대화 잇기 / ⑤ 공감·응원만
- **길이**: 짧게(40~80자) / 보통(80~140자) / 길게(140~200자) — 3개가 같은 길이대에 몰리지 않게
- **공감 무게**: 공감 후 본론 / 공감 위주 / 바로 본론

3개를 나란히 놓고 "이건 아까 거랑 같은 말인데" 싶은 게 있으면 그 하나를 완전히 다른 각도로 다시 쓴다.

## 5. 출력 형식 (채팅에 그대로)

카드 UI를 띄우지 않는다 — 1건이라 채팅이 빠르다.

```
층위: [케이스 A/B/C] · 대화 맥락 한 줄
톤: 존댓말 / 반말   (판단 근거 한 마디)
근거: <slug>        ← 발달장애 주제일 때만. domain-knowledge.md 참고
설계: 1번=관점 재구성 짧게 / 2번=내 경험 보통 / 3번=방법 1개 길게

**1**
[본문]

**2**
[본문]

**3**
[본문]
```

## 6. 발행

- 사용자가 번호를 고르면(또는 고쳐서 주면) 발행한다. **휴먼인더루프는 모드 A와 동일** — 고르지 않은 건 절대 안 나간다.
- 퍼머링크(`/@user/post/CODE`)를 알면 Claude가 `card-ui.md` §발행 절차로 게시한다. 스크린샷만 받아 링크를 모르면 **텍스트를 드리고 직접 붙여넣게** 한다.
- ⚠️ 게시 직전 `document.querySelector('[contenteditable="true"]').innerText`로 **실제 입력값 검증**(card-ui.md 하단). 스크린샷만 믿지 않는다.
- 발행됐으면 `reply-log.md`에 추가하고, 최종본을 초안과 diff해 `voice-profile.md`를 갱신·커밋한다(SKILL §2-8).

## 7. 안전

- 캡처에 **개인 식별 정보**(실명·전화번호·아이 사진·주소)가 있으면 답글에 옮기지 않는다. 답글 자체가 위험할 정도면 마스킹 후 다시 달라고 한다.
- 상대 대댓글이 **시비·악플**이면 추천안을 3개 만들지 말고, **대응하지 않는 선택지**를 먼저 제안한다. 공개 답글은 되돌릴 수 없다.
- 발달장애 주제면 `domain-knowledge.md` §1 정체성 경계와 §5 금지를 그대로 적용한다.
