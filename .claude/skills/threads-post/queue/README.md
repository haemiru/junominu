# 스레드 발행 대기열 (queue/)

하루 6편 × 7일 = **42편**. 하성재님이 **직접 고쳐서 확정**하면, 그 파일을 읽어 Claude가 순서대로 발행한다.

## 파일

| 파일 | 날짜 |
|---|---|
| `2026-08-07-금.txt` | 1일차 (**오늘**) |
| `2026-08-08-토.txt` | 2일차 |
| `2026-08-09-일.txt` | 3일차 |
| `2026-08-10-월.txt` | 4일차 |
| `2026-08-11-화.txt` | 5일차 |
| `2026-08-12-수.txt` | 6일차 |
| `2026-08-13-목.txt` | 7일차 |

> 🕘 **날짜·시각은 전부 한국시간(KST)이다.** 이 PC의 시간대가 Korea Standard Time 이라
> `Get-Date` 값이 곧 KST다 — 따로 변환하지 않는다.

## 고치는 법

- `[본문]` 아래를 자유롭게 고친다. **줄바꿈 그대로 나간다.**
- `[댓글]` 이 `(없음)` 이면 **링크 없이** 나간다. 링크를 달려면 `(없음)` 을 지우고 본문을 쓴다.
- **🔴 표시는 제가 모르는 숫자다.** 확인해서 채우고 🔴 를 지워 주세요. 안 지우면 그 편은 **건너뜁니다.**
- 통째로 빼려면 그 편의 `[본문]` 을 `SKIP` 한 줄로 바꾸면 된다.
- 구분선(`====`)과 머리줄(`[N] 시각 · 프로젝트 · 토픽`)은 **건드리지 말 것** — 그걸로 파싱한다.

## 톤 기준 (2026-08-05 「네○버 의존」 발행본)

1. **숫자·단가로 연다** — `건당 1000~2000원.. 그것도 한 달 지나면 또 다시`
2. **`언제까지 ~해야 하나.....` 문제 제기** (말줄임 길게)
3. **그래서 '제품명'은 ~** (3줄 이내)
4. **지금 상태** (이미 붙였고 / 준비하고 있고)
5. **마무리**
   - 출시 전 제품(중개프로) → **부탁 + 선언** (`조금만 기다려 주세요.. 세상에 없던 ~`). **권유·링크 없음**(규칙 87)
   - 이미 쓸 수 있는 제품 → **권유** (`한 번 구경해 보세요 --`) + 링크는 **첫 댓글**(규칙 24·78)

## 발행 시각 (KST)

기본: `08:10 / 11:10 / 14:10 / 17:10 / 19:40 / 21:00` — 3시간 안팎 간격, 오전 8시~오후 9시 안.

⚠️ **1일차(08-07)만 예외 — 오후 3시 시작**(검토 시간을 벌기 위해, 사용자 지시).
`15:00 / 16:10 / 17:20 / 18:30 / 19:45 / 21:00` — **간격이 약 70분**이다.
15:00~21:00 은 6시간뿐이라 6편을 넣으면 3~4시간 간격이 나올 수 없다. 오늘만 촘촘하게 간다.

**2일차부터는 기본 시각(08:10 시작)으로 돌아간다.** 3시 시작을 계속 쓰려면 하루 편수를 3편으로 줄여야 한다
(`15:00 / 18:00 / 21:00`). 어느 쪽으로 갈지는 사용자가 정한다.

시작이 늦은 날은 **남은 시간에 그날 편수가 들어가도록 그날 것만 다시 잡는다**(오후 9시를 넘기지 않는다).

## 🔴 42편 전부 중개프로다 (사용자 지시 2026-08-07)

다른 프로젝트(아이복지모아·짱샘의 책방·PetPhotoAI 등)는 **나중으로 미룬다.**
정식 출시 전까지 중개프로 하나만 민다.

**전부 출시 전 제품이라 링크·권유가 없다**(규칙 87). 댓글은 42편 모두 `(없음)`.

### 같은 제품 42편이 광고로 안 읽히게 하는 장치

| 무엇 | 어떻게 |
|---|---|
| **훅** | 단가(건당 1000~2000원) · 시간(며칠) · 질문 · 고백(5개월 200번) · 의견("전 아니라고 봅니다") 을 돌려 쓴다 |
| **화자** | 대부분 중개사에게. 단 **08-12 [1][2] 는 「집 구하는 손님」에게** — 토픽도 `#부동산` |
| **성격** | 하루 6편 안에 기능 4 + 만드는 과정 1~2 + 의견/마일스톤 1 |
| **마무리** | `조금만 기다려 주세요..` 를 매번 쓰지 않는다. 질문으로 끝내는 편(08-08 [6], 08-12 [6])도 섞었다 |

⚠️ 그래도 **같은 계정에서 같은 제품 42편은 부담이 큰 편성**이다.
반응(조회·답글)이 3일 연속 죽으면 편수를 줄이거나 다른 축을 섞는 걸 다시 의논한다.
근거: 08-01 판매글 조회 25 — 반응 없는 글이 쌓이면 계정 전체가 눌린다.
