# 하성재 문체 프로필 (학습 누적) — @solopreneur.jm

**두 스킬 공용 단일 원천.** `threads-post`(글)·`threads-reply`(답글) 모두 **초안을 쓰기 전 이 파일을 읽고**, 여기 규칙을 문체에 반영한다.
목적: 하성재님이 발행 직전 손본 흔적을 매번 학습해, AI 초안이 점점 **본인이 실제로 쓰는 말투**에 수렴하게 한다.

## 학습 방법 (발행 때마다 실행)

1. **발행 시점에** 하성재님이 확정(수정했거나 그대로 둔) 최종본을, AI 초안과 **한 편씩 대조(diff)**한다.
2. 바뀐 부분에서 문체 신호를 뽑는다 — 단어 교체, 종결어미, 감정표현(ㅠㅠ/ㅋㅋ/ㅎㅎ/…), 이모지·해시태그 취향, 문장 길이, 질문 방식, 지운 표현(=싫어하는 패턴).
3. 아래 **§규칙**을 갱신하고, **§관찰 로그**에 날짜별 원자료를 남긴다.
4. **커밋·푸시**한다(사용자 지시 2026-07-25: "스킬을 학습하면 커밋/푸시까지").
   - 커밋 메시지 예: `learn(voice): <날짜> 발행본에서 문체 N건 학습`
   - `.claude/skills/threads-post/voice-profile.md`만 스테이징(관계없는 작업트리 변경 섞지 말 것).

> 수정이 **하나도 없어도** 기록한다("이 초안은 그대로 통과" = 그 표현들이 승인됐다는 신호). 반대로 매번 지워지는 표현은 **금지 목록**으로 승격한다.

## §규칙 (초안에 바로 적용 — distilled)

가장 확실한 것부터. 관찰이 쌓이면 규칙으로 승격/수정한다.

1. **감정엔 자모·말줄임을 실제로 붙인다.** 공감·자조 지점에 `ㅠㅠ`·`ㅋㅋ`·`ㅎㅎ`·`..`를 얹어 온도를 올린다. (근거: 2026-07-24 F 발행본 — "따로 놀아요.."에 **ㅠㅠ 추가**)
2. **마무리 질문은 더 '열린' 형태를 선호.** 좁게 유도하는 질문보다 상대가 사연을 풀 여지를 주는 질문. (근거: F 발행본 — 마무리를 "업무 하시는데 **가장 불편한 일은 어떤건가요?**"로 바꿈)
3. **문장은 자연스럽게 풀어 쓴다.** 기계적 대구·정갈한 완결보다, 말하듯 이어지는 리듬. (근거: F 발행본 — 홈페이지 문장을 자연스럽게 리라이트)
4. **해시태그는 더 타겟한 쪽으로.** 넓은 것보다 독자를 정확히 부르는 것. (근거: F — 내 제안 `#부동산` → 본인 `#공인중개사`)
5. **이미지 없이 링크 프리뷰 카드로 내보내기도 함.** 첨부 이미지는 선택. (근거: F — 이미지 미첨부, 링크 카드로 발행)
