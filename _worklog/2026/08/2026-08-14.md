### ⑥ ✅ 검색엔진 등록 — 구글 · 네이버 둘 다 완료 (`2e9e360` · `c6886ea`)

**둘 다 소유확인 완료.** 등록 전엔 meta 태그·DNS TXT·GA 가 전부 없었다(= 미등록 상태였음).

| | 속성 | 확인 방법 |
|---|---|---|
| 구글 서치콘솔 | URL 접두어 `https://www.junominu.com/` | HTML 태그 |
| 네이버 서치어드바이저 | `https://www.junominu.com` | HTML 태그 |

- 소유권 메타 2줄은 `index.html` 에 있다. **`prerender-meta.js` 의 템플릿이라 30개 라우트 전부에 복제된다.**
  🔴 **지우면 소유권이 풀린다.**
- 🔴 **HTML 파일 방식은 이 사이트에서 절대 안 된다** — 처음에 구글이 *"확인 파일에 잘못된 콘텐츠가 있습니다"* 로 실패했다.
  원인은 `vercel.json` 의 SPA fallback: **없는 경로도 404 가 아니라 `index.html` 을 200 으로 돌려준다.**
  실측 — `/google-does-not-exist-test.html` → `HTTP 200`, 우리 앱 HTML. 앞으로 어떤 서비스든 **HTML 태그 방식으로** 갈 것.
  (꼭 파일이어야 하면 `public/` 에 진짜 파일로 넣으면 된다 — Vercel 은 실제 파일을 rewrite 보다 먼저 서빙한다.)
- 네이버의 *"자동등록을 방지하기 위한 보안절차 검증에 실패"* 는 **우리 태그 문제가 아니라 네이버 봇 차단 단계**다.
  새로고침 후 재시도로 통과했다.
- **RSS 피드 신설** (`c6886ea`) — `scripts/prerender-meta.js` 가 `dist/rss.xml` 을 만든다(현재 18개, 글 추가 시 자동).
  `index.html` 에 `<link rel="alternate" type="application/rss+xml">` 도 넣어 자동 발견되게 했다.
  네이버에 RSS 를 제출해 두면 **앞으로 새 글마다 「웹 페이지 수집」에 URL 을 손으로 넣지 않아도 된다.**
  enclosure(이미지)는 `length` 없이는 규격 위반이라 뺐다.
- 제출 상태: **양쪽 다 완료(2026-08-14).** 구글 — 사이트맵 + 새 글 4편 색인 요청. 네이버 — 사이트맵 + RSS.
  → **이제 글을 올려도 검색엔진 쪽에 손댈 일이 없다.** 사이트맵·RSS 가 빌드 때 자동 갱신되기 때문.
  급한 글만 구글 「URL 검사 → 색인 생성 요청」 / 네이버 「웹 페이지 수집」으로 밀어 넣으면 된다.
- ⚠️ 없는 경로가 전부 200 이라 서치콘솔이 나중에 **soft 404** 를 리포트할 수 있다. SPA 의 알려진 트레이드오프 — 뜨면 그때 본다.
